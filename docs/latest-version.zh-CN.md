# 官方 MiXCR v4.7.0 与本项目 Python 移植版

[English](latest-version.md)

截至 2026 年 10 月 12 日核对，官方 GitHub 发布页将 **MiXCR v4.7.0** 标记为 Latest；该版本发布于 2024 年 8 月 7 日。本文固定介绍 v4.7.0，后续发布可能改变最新版本标记。[官方发布页](https://github.com/milaboratory/mixcr/releases/tag/v4.7.0)。

官方此次更新主要涉及跨样本组装特征的一致性、单细胞处理、基因判定以及下游分析修正。

| 领域 | 官方 v4.7.0 更新 |
| --- | --- |
| 组装 | 实验流程未预设组装特征时，需要明确选择；克隆与 contig 组装分别设置命中过滤参数。 |
| 单细胞与条形码 | 修正细胞间读段隔离，按受体链组装共识序列；支持跳过标签纠错，并在 10x VDJ 预设中加入 MiTool 预组装。 |
| 下游分析 | 修正 SHM 树拓扑和导出；`groupClones` 更名为 `assembleCells`。 |
| 参考库与输入 | 增加兔、羊 IG 参考，修正人类参考信息、长读段和 BAM 处理，并增加试剂盒预设。 |

以上内容依据官方发布说明整理。完整参数名称、升级注意事项及全部变更请查阅 [v4.7.0 发布说明](https://github.com/milaboratory/mixcr/releases/tag/v4.7.0)。

**本项目 Python 实现以 MiXCR 3.0.13 为兼容目标。** 当前研究用途范围包括人类 V(D)J 比对、可重叠及未合并双端读段、基因特征提取、克隆组装、部分读段拼接，以及默认 CDR3 contig 重建。验证采用原版 3.0.13 的科学结果作为对照；具体参数范围和输入格式见项目 README。

单细胞条形码纠错、`assembleCells`、等位基因推断、SHM 树构建、MiTool 集成、新版试剂盒预设，以及 v4.7.0 参考库更新，均在本移植版当前支持范围之外。3.0.13 对照测试支持对应流程的兼容性结论，v4.7.0 等价性尚未验证。Python 软件采用自有 JSON 中间格式、TSV 表格和 FASTA contig；原生 MiXCR 二进制格式兼容尚未纳入接口。
